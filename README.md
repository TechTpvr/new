# کیف‌نت v12 — نسخه پیشرفته وب

این بسته فقط نسخه وب کیف‌نت است. هیچ کد، تنظیمات، workflow یا فایل Android/iOS داخل آن وجود ندارد و تمام فایل‌ها در ریشه ZIP قرار گرفته‌اند.

## ویژگی‌های اصلی
- کارکرد آفلاین برای دخل‌وخرج و داده‌های محلی
- Service Worker برای باز شدن برنامه بدون اینترنت پس از اولین بارگذاری موفق
- بازار با تلاش برای نرخ زنده و بروزرسانی خودکار هر ۱ دقیقه هنگام آنلاین بودن
- نبض بازار برای سکه تمام بهار آزادی، طلای ۲۴ عیار و دلار آمریکا در بازه‌های لحظه‌ای، هفته، ماه و سال
- نگهداری آخرین نرخ بازار هنگام قطع اینترنت
- فشرده‌سازی تاریخچه بازار برای جلوگیری از حجیم شدن localStorage
- پشتیبان‌گیری و بازیابی JSON و خروجی CSV
- هیچ قابلیت SMS یا دسترسی سخت‌افزاری موبایل در نسخه وب وجود ندارد؛ مرورگر اجازه خواندن خودکار SMS را نمی‌دهد.

## اجرای محلی
`npm install` سپس `npm run dev` یا برای خروجی نهایی `npm run build`.

## نکته نرخ بازار
نرخ‌های آنلاین به در دسترس بودن و سیاست CORS منابع عمومی وابسته‌اند؛ در صورت عدم پاسخ منبع، آخرین داده ذخیره‌شده نمایش داده می‌شود. برای نرخ تجاری پایدار در مقیاس بالا، بهتر است بعداً یک API اختصاصی سمت سرور به پروژه متصل شود.
